Frequently asked questions What is Agent Toolbox? Agent Toolbox is a small, independent site with free tools for AI agent builders, such as a token cost estimator, a tool-schema converter and a prompt linter, plus a curated directory of agent frameworks and infrastructure.
Is Agent Toolbox free? Yes.
Every web tool is free, with no account.
A paid Pro plan only applies to heavier use of the API and MCP server.
Can AI agents use Agent Toolbox? Yes.
The tools are available as a JSON API, an OpenAPI spec, llms.txt and a hosted MCP server.
See the developer docs .
Does Agent Toolbox store my prompts? No.
The web tools run in your browser, so text you paste is processed on your device.
See the privacy policy .
